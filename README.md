# Comandos-para-rede
Junção de comandos de rede Windows/Linux para auxiliar na resolução de problemas.

## Atenção 
Repositório com a finalidade de armazenar os comandos mais utilizados no meu cotidiano e centralizá-los em um local de fácil acesso. Por essa razão, explicações e detalhes minuciosos de cada comando estão ausentes neste repositório.
